# AI Ethics Discourse in arXiv cs.AI Papers (2018–2025)

Replication materials for a longitudinal study of how AI ethics is framed in academic AI research.

**Central question:** Does institutional affiliation (academia vs. industry) shape how AI ethics is framed in cs.AI papers?

**Hypothesis:** Ethics framing is predominantly technical/managerial (metrics, benchmarks, compliance) rather than substantive (justice, power, harm to communities), and this skew is more pronounced in industry-affiliated work — consistent with Bourdieusian field theory.

---

## Corpus

- **Source:** arXiv cs.AI (primary category only), 2018–2025
- **Sample:** 50 papers/year × 8 years = 400 sampled; 399 PDFs retrieved
- **Missing PDF:** `1911.01156` (AAAI FSS-19 proceedings — not downloadable from arXiv)
- **Stratified random sample:** per-year seed = `RANDOM_SEED + year` (42 + year); see `src/collect.py`
- **Metadata:** `data/raw/arxiv_pilot.csv`
- **PDFs:** `data/pdfs/` — not tracked in git (399 files, ~1.2 GB)

```bash
git clone https://github.com/michellesuminpark/ai-ethics-discourse.git
cd ai-ethics-discourse
conda env create -f environment.yml
conda activate ai-ethics
```

Or with pip:

```bash
pip install -r requirements.txt
```

> BERTopic pulls in `torch` transitively via `sentence-transformers`. On a GPU machine, install PyTorch with CUDA support first, then install the remaining packages.

### 2. Set API key

```bash
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env
```

Scripts load this automatically via `python-dotenv`.

The 399 PDFs are not tracked in git. To retrieve them, run Step 1 (collect) or download them manually from arXiv using the paper IDs in `data/raw/arxiv_pilot.csv`. One paper (`1911.01156`) is not publicly downloadable from arXiv.

## Pipeline steps

### Step 1 — Corpus collection

```bash
python src/collect.py
```

Queries the arXiv API for cs.AI papers (primary category only) by year, samples 50 per year with seed `42 + year`, and downloads PDFs. Per-year checkpoints in `data/raw/checkpoints/` make this safe to interrupt and resume.

- **Input:** arXiv API
- **Output:** `data/raw/arxiv_pilot.csv`, `data/pdfs/*.pdf`
- **Time:** 2–4 hours (arXiv enforces 15-second delays between API pages)
- **Random seed:** `RANDOM_SEED = 42`; per-year seed = `42 + year`

### Step 2 — PDF parsing

```bash
python src/parse.py
```

Extracts two text sets from each PDF using PyMuPDF (fitz):

- **Affiliation text:** first 2 pages + any acknowledgments section
- **Ethics section text:** sections matching target headers (introduction, discussion, conclusion, broader impact, limitations, societal impact); falls back to first 3 + last 3 body paragraphs

- **Input:** `data/pdfs/`, `data/raw/arxiv_pilot.csv`
- **Output:** `data/processed/affiliation_text.csv`, `data/processed/ethics_sections.csv`
- **Time:** ~5 min

### Step 3 — Affiliation classification

```bash
python src/classify.py
```

**Model:** `claude-sonnet-4-6` | **Temperature:** 1 | **Max tokens:** 2048

Sends affiliation text to the Anthropic API and asks for free-form institution type labels per author (no fixed taxonomy). Aggregates to paper level, collapses rare types (< 15 papers → "other"), and validates with LOO-CV.

- **Input:** `data/raw/arxiv_pilot.csv`, `data/processed/affiliation_text.csv`
- **Output:** `results/author_affiliations_raw.csv`, `results/author_affiliations_paper_level.csv`, `results/author_affiliations_collapsed.csv`, `results/loo_cv_results.json`
- **Time:** ~30 min | **Cost:** ~$2 Anthropic API
- **Note:** Checkpoints after each paper; safe to interrupt and resume

> **Reproducibility caveat:** LLM outputs are non-deterministic. Re-running this step will produce semantically equivalent but not bit-identical institution type labels. The pre-computed CSV in `results/` contains the exact labels used in the paper.

### Step 4 — Ethics scoring

```bash
python src/ethics_score.py
```

**Model:** `claude-sonnet-4-6` | **Temperature:** 1 | **Max tokens:** 256

Two-stage LLM coding for all 399 papers:
- **Stage 1 (all papers):** Binary substantiveness — 1 = genuine normative concern (fairness, harm, accountability, justice, governance); 0 = incidental/technical only
- **Stage 2 (substantive papers only):** Thematic category — A (Technical Ethics), B (Governance/Compliance), or C (Structural/Justice)

Full prompts are in `src/ethics_score.py` (`STAGE1_USER`, `STAGE2_USER`).

- **Input:** `data/processed/ethics_sections.csv`
- **Output:** `results/ethics_codes.csv`
- **Time:** ~20 min | **Cost:** ~$2 Anthropic API
- **Note:** Checkpoints after each paper; token usage reported at completion

> **Reproducibility caveat:** Same as Step 3 — LLM non-determinism means re-runs will not produce bit-identical scores. Use the pre-computed CSV for exact replication.

### Step 5 — BERTopic topic modeling

```bash
python src/bertopic_run.py --mode both
```

Runs BERTopic in two modes:

- **ethics mode** (N=44 substantive papers): validates A/B/C theme structure
- **corpus mode** (N=399 papers): maps full cs.AI topic landscape; overlays ethics papers

Embedding model: `sentence-transformers/all-MiniLM-L6-v2`. UMAP `random_state=42`. HDBSCAN `cluster_selection_method="eom"`.

- **Input:** `data/processed/ethics_sections.csv`, `results/ethics_codes.csv`, `results/author_affiliations_collapsed.csv`
- **Output:** `results/bertopic_{ethics,corpus}_{output,topics}.csv`, `results/bertopic_{ethics,corpus}_model/`
- **Time:** ~10 min

> **Reproducibility note:** UMAP includes `random_state=42` for determinism. HDBSCAN is deterministic given fixed UMAP output. Results should be bit-identical across runs on the same machine/OS; minor floating-point differences may appear across platforms.

### Step 6 — Figure generation

```bash
python src/visualize.py
```

Generates all 10 figures as PDF + PNG (300 DPI) in `results/figures/`. Figure 10 (UMAP scatter) re-runs embedding + UMAP and takes ~60 seconds.

- **Input:** all `results/*.csv` + `results/loo_cv_results.json`
- **Output:** `results/figures/fig{1–10}_*.{pdf,png}`

## Design notes

**Why LLM for affiliation classification?** Regex heuristics fail on the diversity of institution names across languages and naming conventions. Free-form LLM labels capture nuance (e.g., distinguishing industry research labs from product teams) without a predefined taxonomy. LOO-CV checks whether the labels are recoverable from text alone, validating their internal consistency.

**Why section-based extraction rather than abstract only?** Ethics framing appears in discussion and conclusion sections, not abstracts. Abstracts describe contributions; discussions situate them normatively.

**Why BERTopic + LLM triangulation?** The LLM coding is judgment-based and provides clean A/B/C categories. BERTopic is fully unsupervised. Agreement between the two (measured as topic-by-theme crosstab + Adjusted Mutual Information) provides a validity check that neither method offers alone.
